# ☁️ KT 板云朵字生成器 · Cloud Letter Maker

给小学英语课堂用的 KT 板云朵字工具：输入英文单词 / 短语 / 句子 → 选模板 → 导出 A4 矢量 PDF → 打印裁剪 → 贴上墙。

**单文件、零依赖、离线可用。** 双击 `index.html` 就能用，不需要 Node、Python、服务器或联网。

## 为什么不是普通文字描边

普通描边是每个字母各描一圈，剪下来是一堆碎块，拼不回一个词。这里做的是**整词连续轮廓**：

1. Canvas 按当前字体把文字画成二值掩膜
2. 用欧氏距离变换（Felzenszwalb & Huttenlocher）算出「到字形的距离场」
3. 在距离场上取等值线（Marching Squares），得到离字形 L 毫米的闭合轮廓
4. RDP 简化 + Chaikin 平滑，变成 SVG / PDF 用的矢量折线

因为外框、内框、文字三层取的是**同一个场的不同等值线**，三层严格平行，边缘天然圆润无尖角，一次就能剪下一整块。

起伏函数（云朵 / 气泡 / 波浪 / 不规则）直接叠在这个场上，振幅上限锁在「文字到内框的空隙」内 —— 否则轮廓会啃进字里。

好处：不依赖字体文件、不依赖 CDN，系统里任何字体都能用；屏幕和 PDF 共用同一份多边形数据，天然所见即所得。

## 功能

**文字与轮廓**
- 英文单词 / 短语 / 多行句子，多行自动合成一整块连续轮廓
- 6 种轮廓：云朵、气泡、圆角、波浪、不规则、无
- 三层描边（外框 + 内框 + 文字），颜色、粗细独立可调
- 纯色或 2–6 色渐变填充、硬偏移立体阴影、圆点/星星/爱心/彩纸/小花装饰
- 3 种字体：**手写体（默认）** / 圆体 / 系统默认；手写体以 base64 内嵌，不依赖系统安装。字号 30–450px，字重 400/700/900，字间距可调

**模板**
- 8 套风格：Cloud / Bubble / Cute / Cartoon / 英语课堂 / Sunny / Star / 单词卡
- 缩略图用同一套轮廓管线渲染，所见即所得；套用后所有参数仍可继续改

**排版与编辑**
- A4 纵向 / 横向，多页，页边距可调，网格吸附，边距参考线
- 拖拽、缩放、旋转，图层上下移动与显隐
- 一键「横向铺满 / 纵向铺满」（按旋转后的包围盒计算，位置不变）
- 对齐（左/中/右、上/中/下）、等距分布、自动排列、适应页面
- 撤销 / 重做，Ctrl+Z / Ctrl+Shift+Z / Ctrl+D / Delete / 方向键微调

**输出与存档**
- 矢量 PDF（A4 精确 595.276×841.89pt），多页，页面裁切
- JSON 工程文件导入 / 导出（顶栏），可换电脑继续编辑
- 编辑自动存本地，刷新不丢

## 快速上手

1. 双击 `index.html`
2. 左侧挑一个模板（没选中元素时会在页面里新建一个）
3. 右侧改文字、字号、颜色、轮廓粗细
4. 右上角「导出 PDF」→ 用 PDF 阅读器打印，选 A4、边距「无」、缩放 100%

> 新建元素：双击画布空白处，或点左侧模板。

> 提示：KT 板字建议外框粗细 ≥ 19px（≈5mm），内框 9–15px（≈2.5–4mm），打印后沿外框剪，中间不用挖。

## 技术

| 项目 | 做法 |
|---|---|
| 画布 | SVG，`viewBox` 单位 = px（96dpi，A4 = 793.7×1122.52px），与打印尺寸 1:1 |
| 轮廓 | Canvas 掩膜 → 距离场 → Marching Squares → RDP + Chaikin |
| PDF | 自研 PDF 1.4 写入器：`m/l/h/f*` 矢量折线、`cm` 矩阵做位移旋转缩放、`re W n` 裁切（px×0.75 = pt） |
| 字体 | 手写体以 base64 内嵌进 CSS（`@font-face`），首次渲染会等字体就绪后自动重描，不会用回退字体出图 |
| 依赖 | 无。全文只有 1 个 `<style>`、1 个 `<script>`，无任何外部请求 |

## 已知限制

- 只在 Chrome（Chromium）实测；Firefox / Safari 未验证，旧版 Safari 会忽略字间距参数
- 单位统一 px（96dpi）；旧版本存的是 mm，读取时会自动换算
- 文字一律居中，无斜体、无左中右对齐、无行间距调节（行距固定 1.12）
- 无元素组合功能；多选请用 Shift+点击
- 无「添加文字」按钮：双击画布空白处或点模板来新建
- 无内置打印预览：导出 PDF 后用 PDF 阅读器打印
- 字体依赖系统：缺失的字体自动回退，不同电脑字形略有差异（矢量输出，清晰度不受影响）
- 阴影是硬偏移色块（为了屏幕与 PDF 完全一致），不是高斯模糊
- 轮廓是折线矢量，放大到 1000% 以上能看到多边形顶点，正常 A4 打印尺寸不可见
